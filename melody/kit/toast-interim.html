Toast setup: interim reward buttons

Melody Bar & Grill · 6 discount buttons · about 10 minutes in Toast Web, done together with Antidote. Use these until the Toast loyalty integration is approved (about 30 days); then rewards apply automatically and guests' points carry over.

How it works for staff: servers never use their own phones. The guest shows a live reward pass on their phone: moving colors, a ticking clock and a 10:00 countdown. A still or gray pass is a screenshot or expired: don't accept it. The pass names the exact Toast button to ring.

2 · Create them in Toast Web

  1. On a computer, sign in to Toast Web (toasttab.com) with a manager or owner login.
  2. Go to Finance › Related › Settings › Discounts & promo codes (on some accounts: Payments › Comps and promos › Discounts and promo codes).
  3. Select + Add a Discount and type the name exactly as in the table. The name is what staff see on the POS and on the receipt.
  4. Set Discount type, the amount and Applies to as listed.
  5. Under Advanced Settings, leave Allow with other discounts off (one reward per check).
  6. If Toast offers it, turn on a required reason / comment so staff type the pass code (e.g. MEL-7K3P).
  7. Save, then publish so the buttons reach the POS devices. Repeat for all 6.

3 · Permissions

  • Server and bartender jobs need Toast's Discounts permission (3.1) so they can apply these buttons.
  • Optional: if you want a manager to OK the bigger ones ($10 Off, Free Entrée), turn on manager approval for discounts on those jobs in Toast. It slows the table down a little; most spots leave it off for the first month.
  • Nobody needs the app on their own phone. The owner / manager spot-check page is in the app's owner view (Interim log).

4 · At the table (print this part for the staff board)

  1. Guest shows the live pass. Check it's moving and the countdown is running.
  2. For a free item: select that item on the check first.
  3. Tap Discounts › the button named on the pass. Type the pass code as the reason, or write it on the merchant copy.
  4. The pass works once. When it hits 0:00 it turns gray: USED / EXPIRED.
  5. One reward per guest per day. The app will not issue a second pass the same day, so there is nothing to turn down at the table — if a guest asks, their next reward is available tomorrow.
  6. Rams Score Special (only on days the Rams score, once it's switched on): same live pass, button App – Rams Score Special. It counts as that guest's one reward: no second reward on the same check.

5 · Daily spot-check (2 minutes)

Open the app's owner view › Interim log. Compare receipt claims (check # + total) with Toast's daily Sales summary / Checks report. Approve the ones that match, Flag the rest. Compare "Rewards used" with the App Reward discounts in Toast's discount report.
