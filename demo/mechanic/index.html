        Electric car

        Option A · Bluetooth adapter

        Plug in a Bluetooth OBD-II reader

        Plug a Bluetooth LE (BLE) ELM327 adapter into the port under the dash, turn the key to ON, then tap Connect. Read-only: this app never clears codes.

        Which adapter works?
        • Veepeak OBDCheck BLE+ (Bluetooth LE, budget)
        • Vgate iCar Pro BLE 4.0 (Bluetooth LE, budget)
        • OBDLink CX (Bluetooth LE, premium, very reliable)

        Get a "BLE" / "Bluetooth 4.0" model. Classic-Bluetooth and Wi-Fi adapters can't talk to a web page. Works in Chrome on Android, Chrome on a computer, and the Bluefy browser on iPhone (Safari on iPhone can't use Bluetooth).

        Option B · Type the code

        Code meanings: standard SAE J2012 generic codes (2,128 built in). Manufacturer-specific codes are looked up by the mechanic.
